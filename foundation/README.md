
# 📚 Data Engineering Foundations

**From Python Fundamentals to Your First Data Pipeline**

## 📌 Overview

This is the first stage of my Data Engineering learning journey.

The Foundation stage focuses on building essential skills in programming, probability and statistics, data analysis, SQL, and basic data engineering concepts.

The learning path combines three structured courses with additional hands-on exercises and practical projects.

**Main Objective:** Develop a solid technical foundation and gain the ability to build a basic end-to-end data pipeline.

## 🎯 Learning Objectives

By the end of this stage, I aim to:

- Write clean, structured, and maintainable Python code.
- Understand basic probability and statistical concepts.
- Process, clean, and analyze datasets using Python.
- Query and manage relational data using SQL.
- Understand how data moves between different systems.
- Build a beginner-level ETL pipeline.
- Apply knowledge through practical exercises and projects.

## 🗺️ Learning Roadmap

### Phase 01 — Python Fundamentals

**Course:** CS50's Introduction to Programming with Python

Topics:
- Variables, data types, and operators
- Conditionals and loops
- Functions and modules
- Exceptions and debugging
- File I/O and regular expressions
- Object-Oriented Programming
- Unit testing

**Expected Outcome:** Independently develop small Python applications and solve programming problems.

### Phase 02 — Probability, Statistics & SQL

Topics:
- Descriptive statistics
- Basic probability
- Probability distributions
- Statistical reasoning
- Relational database fundamentals
- SQL queries, joins, and aggregations

**Expected Outcome:** Understand datasets, interpret statistical results, and retrieve information from relational databases.

### Phase 03 — Data Analysis with Python

Topics:
- NumPy and Pandas
- Data cleaning and transformation
- Exploratory Data Analysis (EDA)
- Data visualization with Matplotlib
- Introduction to basic predictive modeling, where covered by the course

**Expected Outcome:** Analyze and transform real-world datasets using Python.

### Phase 04 — Data Engineering Fundamentals

Topics:
- Data engineering concepts
- ETL and ELT processes
- Data ingestion and transformation
- PostgreSQL
- Basic pipeline automation
- Data quality and validation

**Expected Outcome:** Build a simple end-to-end data pipeline.
